# CodeTyping — 编程打字练习

在浏览器里敲真实代码，练打字速度的同时熟悉语法。

## 功能

- 🎯 **内置题库** — TypeScript、JavaScript、CSS 代码片段
- 📋 **粘贴模式** — 粘贴自己的代码来练习
- ⏱️ **自由模式** — 不限时，关注准确率
- ⏳ **限时模式** — 30/60/120/300 秒倒计时挑战
- 📊 **实时统计** — WPM、准确率、进度

## 技术栈

- React 19 + TypeScript
- Vite
- Tailwind CSS v4

## 本地运行

```bash
npm install
npm run dev
```
